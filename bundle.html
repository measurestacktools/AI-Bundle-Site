Before you run the projects: get your free Groq API key (2 minutes)

Your own Groq API key is required for AI features. It is not included with the purchase.

  1. Go to console.groq.com/keys and sign up or log in (free).
  2. Click “Create API Key”. Give it any name, e.g. my-projects.
  3. Copy the key. It starts with gsk_ — it is shown only once, so copy it now.
  4. Use it in any project, two ways:
    A) Open the project's .env file and set GROQ_API_KEY=gsk_…your key…, then restart the app — or
    B) Start the app, open Settings, and paste the key there (lasts until you stop the app).

Free tier, no card required. Never share your key publicly or commit a .env file to GitHub.
